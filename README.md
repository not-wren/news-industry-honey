A "website" about investigating angels. It would be more apt to call it a linear hypertext poem.
<p>I made it in CSS and HTML, along with the use of ASCII art.</p>
My initial idea for this website came from the idea of angels being ill and the 1990's Dread Not ARG.
<p>This is the longest it's taken me to code a website so far, and I did get a bit sick of it towards the end.</p>
<p>I learned how to shift text-gradients and how to hide a cursor on a web page, in addition to figuring out how to create a more frighting atmosphere than a typical web site would have.</p>
<p>Unfortunately I couldn't use the flashlight effect with an image background, as it relies on having a white background.</p>


<p>Flashing Lights Warning: this website switches between white and black quickly, and it is not reccomended for those with photosensitive epilepsy to play.<p/>
